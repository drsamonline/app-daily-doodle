Daily Doodle

One drawing prompt a day. The drawing is kept; the streak counts only the days you actually drew.

Status Built and working: a prompt a day derived from the date; a drawing pad; one doodle per date, with a second refused unless you confirm the replacement; yesterday's one tap away; a streak that counts consecutive days actually drawn; a share card with the prompt and the drawing; and an export.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: a global reveal, an account, or any server to reveal anything on. There is no gallery and no ranking, because the spec forbids ranking the drawings.

What it does

  • Gives one prompt a day, the same for every date and derived from it.
  • Keeps the drawing as strokes, on the device.
  • Refuses a second doodle on the same date until you confirm the replacement.
  • Counts a streak of consecutive days actually drawn — a missed day is a gap.
  • Makes a share card with the prompt and the drawing.

What it will not do

  • Rank the drawings. No score, no vote, no gallery order.
  • Fill a gap with the nearest drawing. A gap is a gap.
  • Keep two doodles for one date without you saying so.
  • Start an empty book over a broken one. That would look like a lost streak.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA doodle with no strokes is refused, with or without a replacement; a bad date is refused.
No networkNothing changes; the drawings are on the device.
Storage full or unavailableNOT SAVED, and the drawing on screen is unchanged.
Corrupt saved stateReported and offered for export; never replaced with an empty book.

How to run it

  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
